📲 Pasos para la Instalación en Teléfono Android

1. Permitir instalación de fuentes desconocidas.

- Abre la aplicación de Configuración en tu dispositivo.

- Navega a Seguridad o Privacidad.

- Activa la opción "Fuentes desconocidas". Esto permitirá la instalación de aplicaciones que no provengan de Google Play Store.

- En algunas versiones de Android, esta opción se configura por aplicación.

- Por ejemplo, deberás permitir que el navegador Chrome o tu gestor de archivos tenga permiso para instalar aplicaciones desconocidas.

2. Instalación de la aplicación

- Usa un gestor de archivos (como Files o File Manager) para navegar hasta la ubicación del archivo APK de Mi Salud en tu dispositivo.

- Toca el archivo APK para iniciar el proceso de instalación.

- Aparecerá una ventana solicitando permisos; revisa y acepta para continuar.

- La instalación comenzará y, una vez completada, verás un mensaje indicando que la aplicación se ha instalado correctamente.

- Después de la instalación, puedes abrir la aplicación directamente desde la ventana de instalación o buscarla en tu lista de aplicaciones.
