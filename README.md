MiSalud-Android is a mobile application developed for android devices. It is designed to help patients and monitor their health-related activities,
such as daily meals and physical exercises. The purpose of this app is to support doctor-patient communication and continuous health monitoring.

Its main features are: daily logging for exercises and meals, patient progress tracking, clean and user friendly interface, modular architecture
based on Android development best practices.

This project is collaborative effort among multiple developers.
